# architectural-design-website2
Mvelo Architects is a fictional architectural design website project. This specific section focuses on the **Contact Page**, designed to allow users to send inquiries and view company contact details in a clean, responsive layout. The goal of this project was to practice modern front-end development skills, including form design, layout structuring, and responsive web design.

- Responsive Design (Media Queries)
